Meu primeiro projeto em Java, desenvolvido para praticar lógica de programação e Programação Orientada a Objetos.

- Listar contatos cadastrados.
- Pesquisar contatos pelo nome.
- Remover contatos.

Projeto desenvolvido para praticar lógica de programação, organização de código e manipulação de tarefas em Java.
