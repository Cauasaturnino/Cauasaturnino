## 📂 Projetos

### 🚲 [Sistema de Locação de Mobilidade Urbana](https://github.com/Cauasaturnino/Mobilidade_Urbana_Java)

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Último commit](https://img.shields.io/github/last-commit/Cauasaturnino/Mobilidade_Urbana_Java?style=flat-square&label=%C3%BAltimo%20commit)

Aplicação em Java que simula um sistema de mobilidade urbana compartilhada, com gerenciamento de usuários, estações e veículos (bicicletas e patinetes elétricos).

<details>
<summary><b>Ver funcionalidades e conceitos aplicados</b></summary>

<br/>

**Funcionalidades**
- Cadastro de usuários, estações e veículos
- Locação de veículos disponíveis na estação correspondente
- Devolução em qualquer estação cadastrada
- Cálculo automático da tarifa por tempo de uso e tipo de veículo
- Recarga de bateria dos patinetes elétricos
- Validação de regras: bloqueia veículos indisponíveis e usuários com locação ativa

**Conceitos de POO aplicados**
- **Encapsulamento:** atributos protegidos com acesso controlado por métodos
- **Herança e classe abstrata:** classe base `Veiculo` com comportamentos comuns
- **Polimorfismo:** tarifa calculada conforme o tipo de veículo
- **Interfaces:** `Recarregavel` para o comportamento de recarga dos patinetes
- **Organização:** separação entre `modelo` e `servico`

</details>
